Overview

The CardComponent is a reusable Angular component that represents a card with various properties for customization. It can be used to display information such as a title, type, date, duration, total questions, user avatars, and an associated link. The component also allows customization of the icon, icon color, and icon background color.

            Overview
            

              The MetricComponent is designed to display a set of metrics, each
              represented by an object conforming to the MetricI interface. Each
              metric object contains information such as an optional icon,
              additional information, count, extra value, and an optional
              action.
